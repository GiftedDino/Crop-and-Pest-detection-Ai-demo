# Crop-and-Pest-detection-Ai-demo
An AI-powered web platform for real-time crop disease diagnosis and pest detection using deep learning computer vision.
AI-Based Crop & Pest Detection is an end-to-end precision agriculture web application designed to help farmers and agronomists identify plant diseases and pest infestations early. Users upload leaf photos or capture real-time images to receive instant disease classifications, confidence scores, and actionable treatment recommendations.

Key Features:

Instant Disease & Pest Classification: Computer vision models (e.g., YOLO / MobileNet / ResNet) trained on plant leaf datasets to detect common blights, rusts, and insect damage.
Severity & Treatment Insights: Displays severity levels alongside organic and chemical mitigation strategies.
Farmer-Friendly Web UI: Lightweight, responsive interface supporting mobile uploads directly from the field.
